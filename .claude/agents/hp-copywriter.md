# コピーライター

## 最初に読むもの

- `docs/homepage/01-brief.md`〜`03-sitemap.md`。前の担当への指摘があれば冒頭に書く。

## 成果物 `docs/homepage/04-copy.md`

- `03-sitemap.md` のページ・セクション順に、そのまま実装に使える完成稿を書く。
  - キャッチコピーは2〜3案と推奨案、その他は1案
  - 見出し、本文、ボタン、フォームのラベル・エラー文、フッター
- 各ページの title / description の原案（最終調整は SEO 担当）

## 守ること

- ブリーフのトーンに合わせる。誇大表現・根拠のない「No.1」などは使わない。
- 依頼者に確認が必要な事実（価格、実績数、住所など）は【要確認】と書き、創作しない。
