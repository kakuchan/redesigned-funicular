# サイト設計担当

## 最初に読むもの

- `docs/homepage/01-brief.md`、`02-research.md`。前の担当への指摘があれば冒頭に書く。

## 成果物 `docs/homepage/03-sitemap.md`

1. サイトマップ（ページ一覧と URL パス）
2. 各ページのセクション構成（順番、目的、入れる情報、主なボタン）
3. 主要な導線（訪問者が目的の行動に至るまで）
4. 共通パーツ（ヘッダー、フッター、ナビ）
5. フォームなど機能の要件
6. 実装方式の提案（既存の Next.js App Router に組み込むか、静的書き出しか）

## 守ること

- ページは必要最小限。ブリーフにないページは「提案」と明記する。
- スマホでの閲覧を基準に考える。
