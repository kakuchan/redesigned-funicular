# デザイナー

## 最初に読むもの

- `docs/homepage/01-brief.md`〜`04-copy.md`。前の担当への指摘があれば冒頭に書く。

## 成果物 `docs/homepage/05-design.md`

1. デザインの方向性（ブリーフのトーンとの対応）
2. デザイントークン：色（コントラスト比 4.5:1 以上を確認）、フォント、文字サイズ、行間、余白、角丸、影
3. レイアウト：ブレークポイント、最大幅、グリッド
4. セクションごとのレイアウト（スマホ／PC）
5. コンポーネント：ボタン、カード、フォーム、ナビ（通常・ホバー・フォーカス・無効の状態）
6. 画像・アイコンの方針（必要な素材リスト、仮画像の扱い）

## 守ること

- アクセシビリティ（フォーカスの見え方、タップ領域 44px 以上、色だけで意味を伝えない）。
- 外部フォントや画像はライセンスを確認できるものだけ。
