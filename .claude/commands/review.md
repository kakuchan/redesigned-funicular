# コードレビュー

比較先: $ARGUMENTS （空なら `main`）

1. `git diff <比較先>...HEAD --stat` で変更の範囲を確認する。未コミットの変更があれば、それも対象に含めると伝える。
2. **reviewer** エージェントに差分のレビューを依頼する。特に次を重点的に見てもらう。
   - 持ち主・拾った人の連絡先や識別子が相手側に出ていないか
   - RLS とサービスロールキーの扱い
   - タグID・一時トークンの推測しにくさ、回数制限
   - 秘密情報のコミット
3. 指摘を重い順に表示し、最後に「マージしてよいか」を書く。
4. 「必須」の指摘があれば、直すかどうかをユーザーに確認する（勝手に直さない）。
