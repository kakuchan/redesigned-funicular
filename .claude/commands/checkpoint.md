# セッション状態の保存

`.claude/checkpoint.md` を、次の内容で **上書き** してください（履歴は git に残るので追記しない）。

1. 日時（JST）と、現在のブランチ・最新コミット（`git log -1 --oneline`）
2. 今やっていたタスク（ID とタイトル）と、どこまで終わったか
3. 未コミットの変更（`git status --short` の要約）
4. 次にやること（具体的に、次のセッションがすぐ着手できる粒度で）
5. 詰まっていること・ユーザーに確認待ちのこと
6. 覚えておくべき前提（今回わかった落とし穴など）

あわせて、該当タスクファイルの作業ログと `.claude/progress.md` も更新する。

ユーザーからのメモ: $ARGUMENTS
