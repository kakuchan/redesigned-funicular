# 朝のスタートアップ

次の順で状況を確認し、今日の計画を出してください。

1. `.claude/checkpoint.md` を読み、前回どこで止まったか・次にやることを確認する。
2. `.claude/progress.md` と `.claude/tasks/` を読み、`doing` と `blocked` のタスクを一覧にする。
3. `git status`、`git log --oneline -10`、現在のブランチを確認する。未コミットの変更があれば伝える。
4. `.claude/decisions.md` の「未決事項」で、今日の作業に関係するものがあれば挙げる。
5. 今日やることを **3つまで** に絞って提案する（理由つき）。拾った人が使う流れをつなぐものを優先する。

出力の形:

- 前回の続き: （1〜2行）
- 進行中 / 詰まっている: （箇条書き）
- 今日やること: 1. 2. 3.
- 確認したいこと: （あれば）
