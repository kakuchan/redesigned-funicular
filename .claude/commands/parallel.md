# 並列開発（Agent Team）

対象: $ARGUMENTS

1. **選定**: 対象のタスクファイルを読む。省略時は `.claude/tasks/` から `parallel: yes` かつ `depends` が満たされた `todo` を最大3つ選ぶ。
2. **衝突チェック**: タスク同士が同じファイル（特に `supabase/migrations/`、共通の型定義、共通コンポーネント）を触らないか確かめる。触るなら並列にせず、順番に行う。
   - マイグレーションは衝突しやすいので、DB変更を含むタスクは同時に1つまで。
3. **割り当て**: 各タスクについて、Agent ツールで **developer** を `isolation: "worktree"` で起動する。依頼文にはタスクファイルの内容、完了条件、ブランチ名 `feature/<タスクID>-<短い名前>` を含める。各タスクの状態を `doing` にする。
4. **テストとレビュー**: 終わったタスクから **tester** → **reviewer** の順に通す。
5. **まとめ**: 全タスクについて、ブランチ・結果・テスト結果・レビューの必須指摘の有無を表にする。`.claude/progress.md` を更新する。
6. マージや push はユーザーの確認を取ってから行う。統合の順番（どのブランチを先に入れるか）も提案する。
